# Setup

## Requirements

To play Pandemonium on archipelago requires:

- [Archipelago](https://archipelago.gg) installed
- The latest copy of [the Pandemonium AP World](https://github.com/riezahughes/PandemoniumAPWorld/releases)
- A LEGAL Rom dump of Pandemonium's NTSC(U) version (SLUS-00232)

# Steps

- Install the APWorld in Archipelago
- Generate the templates
- Copy and paste a copy of the Pandemonium template into the `players` folder of your archipelago install. If it doesn't exist, make it.
- Edit the yaml, changing the slot name
- Generate the game
- Host the game using the zip that's generated in your `output` folder of your archipelago install
